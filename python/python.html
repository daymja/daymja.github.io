# Python ## Index - [Installation](#installation) - [Selenium](#selenium) ## Installation 1. Download Python from [here](https://www.python.org/downloads/) 2. Recommend downloading the ***Windows installer (64-bit)*** 3. Confirm Python is installed, open terminal and type ```python py --version ``` You should see something like this ```python Python 3.12.4 ``` 4. Ensure you can run Python Packages, type ```python py -m pip --version ``` You should see something like this ```python pip 24.1.2 from C:\Users\%username%\AppData\Local\Programs\Python\Python312\Lib\site-packages\pip (python 3.12) ``` 5. You can upgrade using ```python py -m pip install pip --upgrade ``` 6. Confirm (or add) Python to your Windows PATH 7. I would recommend coding your Python in [Visual Studio Code](https://code.visualstudio.com/) with Python Extensions installed ## Selenium 1. Install Selenium Python package, open terminal and type ```python py -m pip install selenium ``` 2. Confirm version installed ```python pip show selenium ``` 3. Install Selenium webdriver-manager ```python pip install webdriver_manager ``` 4. Install Colorama for adding colours to your output results ```python py -m pip install colorama ```
