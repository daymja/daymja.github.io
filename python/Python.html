  • Download Python from [here](https://www.python.org/downloads/)
  • Recommend downloading the Windows installer (64-bit)
  • Confirm Python is installed, open terminal and type
py --version

You should see something like this

Python 3.12.4

Ensure you can run Python Packages, type

py -m pip --version

You should see something like this

pip 24.1.2 from C:\Users\%username%\AppData\Local\Programs\Python\Python312\Lib\site-packages\pip (python 3.12)

You can upgrade using

py -m pip install pip --upgrade

Confirm (or add) Python to your Windows PATH

I would recommend coding your Python in [Visual Studio Code](https://code.visualstudio.com/) with Python Extensions installed

Selenium

Install Selenium Python package, open terminal and type

py -m pip install selenium

Confirm version installed

pip show selenium

Install Selenium webdriver-manager

pip install webdriver_manager

Install Colorama for adding colours to your output results

py -m pip install colorama
