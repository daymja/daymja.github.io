Python Installation

[1] Download Python from [here]

[2] Recommend downloading the Windows installer (64-bit)

[3] Confirm Python is installed, open terminal and type

py --version

[4] You should see something like this

Python 3.12.4

[5] Ensure you can run Python Packages, type

py -m pip --version

[6] You should see something like this

pip 24.1.2 from C:\Users\%username%\AppData\Local\Programs\Python\Python312\Lib\site-packages\pip (python 3.12)

[7] You can upgrade using

py -m pip install pip --upgrade

[8] Confirm (or add) Python to your Windows PATH

I would recommend coding your Python in [Visual Studio Code] with Python Extensions installed

Selenium Python Installation

[1] Install Selenium Python package, open terminal and type

py -m pip install selenium

[2] Confirm version installed

pip show selenium

[3] Install Selenium webdriver-manager

pip install webdriver_manager

[4] Install Colorama for adding colours to your output results

py -m pip install colorama
