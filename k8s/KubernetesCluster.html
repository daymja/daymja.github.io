Kubernetes Cluster

Grid Deployment

[1] Download this git repository

[2] Unzip contents into a new folder for example C:\git\seleniumgrid

[3] Launch Docker desktop

[4] Open a terminal and navigate to C:\git\seleniumgrid

[5] Check which cluster you are on by (a) Docker icon menu - kubernetes or (b) Type command

kubectl config get-contexts

[6] Create new cluster namespace, type command

kubectl create -f sgrid/namespace.yaml

[7] Confirm namespace is created, type command

kubectl get namespaces

[8] Update config to use new namespace, type command

kubectl config set-context --current --namespace=selenium-grid

[9] Create the grid hub deployment, type command

kubectl create -f sgrid/hub-deployment.yaml

[10] Confirm deployment is created, type command

kubectl get deployments

[11] Create the grid services, type commands

kubectl create -f sgrid/hub-service.yaml

kubectl create -f sgrid/hub-service-pubsub.yaml

[12] Comfirm services are created, type command

kubectl get services

[13] Create the browser nodes, type command

kubectl create -f sgrid/node-chrome-deployment.yaml

or

kubectl create -f sgrid/node-firefox-deployment.yaml

[14] Confirm pods are created and running, type command

kubectl get pods

[15] Any pods not started, reboot using command

kubectl rollout restart deployment deployment_name

[16] Expose the pods IP addresses, type command

kubectl expose deployment selenium-hub --type=LoadBalancer --name=selenium-hub

[17] Expose the services to the internet, type command

kubectl create -f sgrid/hub-deploy-ingress.yaml

[18] Get the URL address for yout grid, type command

kubectl get ing

Grid Deployment Rollback

Type these commands in sequence

kubectl get all -n selenium-grid

kubectl get service

kubectl delete service your_service_name

kubectl get deployments

kubectl delete deployment deployment_name

kubectl delete pod

kubectl delete replica replicaset_name

kubectl delete namespace namespace_name
