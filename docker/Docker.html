Docker Compose

Launch Grid Docker Image

[1] Download this git repository

[2] Unzip contents into a new folder for example C:\git\seleniumgrid

[3] Launch Docker desktop

[4] Open a terminal and navigate to C:\git\seleniumgrid

[5] Check which cluster you are on by (a) Docker icon menu - kubernetes or (b) Type command

kubectl config get-contexts

[6] Type command

docker compose -f docker-compose.yml up

[7] Once all images have downloaded, open web browser and navigate to http://localhost:4444 which will display the Selenium grid (containing edge, chrome and firefox browser versions)

End and Remove Grid Docker Image

[1] In the Terminal running docker compose, type CTRL + C

[2] Type command

docker compose -f docker-compose.yml down

Update Grid Docker Image

Edit the docker-compose.yml file

Update the following docker images to the latest version as detailed [here]

node-chrome:x.x.x

node-edge:x.x.x

node-firefox:x.x.x

hub:x.x.x
